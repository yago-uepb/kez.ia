# SOBRE

Diretório preparado para realizar os testes de submissão de resolução de questões sem necessidade do Front-end, mas agrupando as facilidades do editor de código.

# INSTRUÇÕES

Garanta que você esteja no diretório [back-end/](/back-end) para as instruções a seguir funcionarem.

Além disso, antes de partir para resolução das questões, considere ler as [Regras de Resolução](../../README.md#regras).

## Para buscar uma questão:

- Modifique a variável `problem_id` de [get_problem.py](./get_problem) para resgatar a questão que você deseja.

- Execute `python -m __tests__.get_problem` no terminal.

## Para submeter sua resolução:

- Insira seu código no arquivo [attempt.py](./submit.py)

- Execute `python -m __tests__.submit` no terminal.
